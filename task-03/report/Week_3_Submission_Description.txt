For the Week 3 frontend engineering assignment, I developed the interactive user experience for ApexHub Innovation Space—a modern, dynamic web platform for collaborative tech coworking and prototyping labs. Building upon the semantic HTML5 foundation from Week 1 and responsive CSS3 architecture from Week 2, this project integrates production-grade Vanilla JavaScript (ES6+) without external dependencies, libraries, or frameworks.

The interactive layer transforms the static website into an engaging, stateful application across eight core modules: (1) an Appearance Theme Switcher that persists user preference (Light/Dark mode) in localStorage and dynamically updates CSS custom properties; (2) a responsive Mobile Navigation Drawer with focus management, backdrop dismissal, and an active Scrollspy tracking user reading position; (3) dynamic Space Catalog Filter Tabs enabling immediate category filtering with smooth opacity transitions; (4) a real-time Multi-Tier Pricing Calculator that computes headcount scaling, optional infrastructure add-ons, and a 20% annual discount using animated requestAnimationFrame number counters; (5) W3C WAI-ARIA compliant FAQ Accordions with keyboard navigation and arrow-key focus traversal; (6) a comprehensive Client-Side Tour Booking Form featuring real-time input sanitization, dynamic character counters, accessible visual error alerts, and an instant reservation confirmation card generating unique ticket reference identifiers; (7) a floating Back-to-Top button; and (8) IntersectionObserver scroll reveals that respect user reduced-motion preferences.

Integration between HTML, CSS, and JavaScript was achieved through event delegation, data-* attributes, and WAI-ARIA live state mutations. The application underwent rigorous automated testing using Playwright headless Chrome, verifying zero horizontal overflow (0px) across all viewports (320px Small Mobile, 375px Standard Mobile, 768px Tablet, and 1440px Desktop), complete asset integrity (100% loaded images), and zero console errors. This assignment solidified my expertise in scalable DOM manipulation, accessible UI engineering, state synchronization, and automated quality assurance.
